# TopData · 网页内容采集插件 需求文档（PRD）

| 项目 | 内容 |
|---|---|
| 应用名称 | **TopData** |
| 版本 | v0.8（提取节点列表集合 + 字段映射点选） |
| 日期 | 2026-11-11 |
| 产品形态 | Chrome 浏览器扩展（Extension） |
| 一句话描述 | 通过节点编排定义"打开网页 → 提取内容/下载图片 → 组装成文"的采集流程，一键产出 Markdown 文档 |

---

## 1. 背景与目标

内容工作者（编辑、运营、研究者、自媒体作者）经常需要从网页摘取素材：标题、正文段落、链接、封面图等，再整理成可发布的文档。现状是手动逐段复制、手动补格式、手动存图，页面一多就重复且易错。

**产品决策**：做一个 Chrome 扩展，让用户用"节点编排"的方式描述采集流程，由插件自动执行并把结果整理成 Markdown：

```
[打开标签页] → [提取：标题] → [提取：正文] → [下载图片：封面] → [文章组装] → 复制 / 下载 .md
```

**目标（可观察结果）**：

- 用户不写代码，仅通过配置节点，即可完成一次采集并拿到 Markdown 文档；
- 流程执行失败时，用户能定位到具体是哪个节点、什么原因失败；
- 结构相似的页面，只需修改选择器即可复用同一套流程。

---

## 2. 产品契约

| 项 | 定义 |
|---|---|
| 主要用户 | 需要从网页采集素材并整理成文档的内容工作者 |
| 触发 | 用户点击浏览器工具栏的扩展图标，在弹窗中管理工作流、进入编辑器 |
| 核心任务 | 搭建一条采集工作流并运行，获得 Markdown 文档 |
| 完成条件 | "文章组装"节点成功产出 Markdown，用户完成复制或下载 |
| 核心对象 | **工作流（Workflow）**：一个起始节点 + 若干执行节点 + 最多一个组装节点，节点间线性串联，靠"命名变量"传递数据；可保存多套，按需运行 |
| 信任前提 | 全部数据在本地处理，不上传任何服务器；采集能力受目标网站的访问权限约束（插件复用用户当前浏览器会话） |

## 3. 范围

### 3.1 P0（本期必须）

- **工作流管理**：多套工作流的新建、重命名、删除、选择进入编辑；列表项展示名称 + 更新时间（相对时间），右侧 ▶ 运行、⋯ 菜单（重命名 / 删除）；
- **图标弹窗**：点击扩展图标弹出工作流列表，列表样式与编辑器主页一致；
- **保存 / 导入 / 导出**（v0.6）：手动保存当前工作流、导出当前工作流、导出全部工作流为 JSON、从 JSON 导入（可合并多套流程）；
- 工作流编辑器（全页标签页形态）：添加、删除、排序、配置节点，运行流程；
- 六类节点：**打开标签页**（起始节点）、**提取内容**（文本 / 属性值）、**批量提取**（集合变量，可翻页）、**下载图片**、**循环**、**条件分支**、**文章组装**（特殊汇总节点）；
- **选择器双语法**：CSS 或 XPath；提取类节点支持**正则后处理**（pattern / flags / replacement）；
- **可视化选择面板**：在网页上打开可拖动的选择面板，开关控制选择态，可切换 CSS / XPath，展示并支持复制元素选择器与全部属性；编辑器内确认后回填；新增**多元素匹配**按钮，开启后自动切换为同类选择器并高亮全部匹配元素（v0.7）；
- **集合变量与循环**：批量提取产出 list 集合变量（列表页批量提取、翻页累积、多图地址批量获取）；支持**字段映射**把每个列表项变成 `{id, name, date}` 形式的对象，模板中用 `{{item.字段名}}` 引用（v0.7）；循环节点遍历集合，区间内节点逐项执行；
- **条件分支**：按变量是否为空 / 相等 / 包含 / 大小比较决定分支内节点是否执行；
- 线性顺序执行（含区间块递归），逐节点状态反馈，失败定位与提示；
- 节点产出命名变量，文章组装节点通过 `{{变量名}}`、`{{#each 集合}}…{{/each}}` 引用；
- Markdown 结果：预览、一键复制、下载 `.md`；循环内组装可产出多篇，支持逐篇切换与批量下载；
- 图片下载到本地，并在 Markdown 中生成引用；支持按变量 URL 在循环中批量下载多图；
- 全部工作流内容本地暂存，刷新或重开不丢失。

### 3.2 P1（后续版本，本期不做）

- 定时自动运行；
- 条件分支的 else 分支语法糖（当前通过取反条件实现）；
- 整页跳转式翻页（当前仅支持点击不刷新整页的翻页）。

### 3.3 明确不做

- 账号体系与云端同步；
- 任何形式的反爬对抗（验证码识别、IP 代理等）；目标页需要登录时，依赖用户自行在浏览器中登录；
- 图片以外的文件下载（视频、附件等）。

## 4. 核心概念与整体流程

### 4.1 术语

| 术语 | 定义 |
|---|---|
| 工作流 | 一条线性节点序列，是编辑和运行的最小单位 |
| 节点 | 工作流中的一个步骤，有类型、配置项和运行状态 |
| 起始节点 | "打开标签页"节点，每个工作流有且仅有一个，固定为第一个节点 |
| 组装节点 | "文章组装"节点，每个工作流最多一个，消费变量产出 Markdown |
| 变量 | 提取 / 下载节点产出的命名结果，供后续节点以 `{{变量名}}` 引用 |

### 4.2 整体流程

```
点击扩展图标 → 弹窗展示工作流列表
   │
   ▼ 选择工作流（或在弹窗/主页新建）
工作流编辑器（全页标签页）
   │
   ▼
搭建工作流：起始节点(打开标签页) → 若干提取/下载节点 → 组装节点
   │
   ▼ 点击"运行"（或从弹窗直接"运行"）
运行前校验（必填项、变量名唯一、模板引用已定义）
   │
   ▼ 校验通过
顺序执行各节点，实时展示节点状态
   │
   ▼ 全部成功
展示 Markdown 预览 → 用户复制到剪贴板 或 下载 .md 文件
```

**数据流**：每个"提取内容 / 下载图片"节点产出一个命名变量（文本值）；后续节点（主要是组装节点）通过变量名引用其值。变量只在单次运行内有效，运行结束即丢弃。

## 5. 功能需求

### FR-01 工作流管理与编辑器

**目的**：用户管理多套工作流，并搭建、配置、运行单个工作流的唯一入口。

**触发**：从图标弹窗（FR-08）点击"编辑 / 工作流名称 / 新建"，或在编辑器主页操作。

**形态**：全页标签页（v0.4 变更，再次推翻决策 #1 的 Side Panel 方案——多套工作流管理需要更大展示空间，弹窗已承担快捷入口职责）。页面含两种视图：

- **工作流列表主页**（默认视图）：按最近更新排序展示全部工作流，每行 = 名称 + 更新时间（相对时间，如"3 小时前"）+ 右侧 **▶ 运行** 与 **⋯ 更多**（重命名 / 删除）；点击名称进入编辑；顶部提供 **导入** 与 **新建工作流**；
- **节点编辑器**（进入某个工作流后）：编辑节点与运行，顶部栏「← 列表」「工作流名称」「文件 ▾（保存 / 导出当前 / 导出全部 / 导入）」「全局设置」「运行」；

**布局**（节点编辑器，左右分栏）：

```
┌─────────────────────────────────────────┐
│ 顶部栏：←列表  名称   [文件▾][设置][运行]  │
├──────────────┬──────────────────────────┤
│ 节点流程      │ 节点配置（随类型变化）      │
│  ① 打开标签页  │                          │
│  ② 批量提取    │                          │
│  ③ 循环        │                          │
│    ├ 提取      │                          │
│    └ 循环结束  │                          │
│  ④ 条件分支    │                          │
│  ⑤ 文章组装   │                          │
│  [+ 添加节点] │                          │
├──────────────┴──────────────────────────┤
│ 日志 | 输出摘要 | MD结果                  │
└─────────────────────────────────────────┘
```

**规则**：

- 支持多套工作流，全部本地暂存（含各工作流节点及配置），关闭或刷新后重新打开时恢复；旧版本单工作流数据自动迁移为一套工作流；
- 新建工作流时自动创建"打开标签页"起始节点，不可删除、不可移动位置；
- 节点操作：在末尾或选中节点之后添加、删除（起始节点除外）、上下移动调整顺序；循环 / 条件为**区间块**，添加时自动插入配对的"循环结束 / 条件结束"，区间内节点按层级缩进，删除块开始节点会连同整个区间一并删除；
- 运行期间编辑器锁定，禁止增删改节点与切换离开，避免与执行快照不一致；
- 顶部栏提供全局设置入口：**页面加载超时时间**（10–120 秒，默认 30 秒）、**图片下载子文件夹名**（默认 `{插件名}/images/`，可自定义，仅允许子文件夹名，不支持绝对路径）。

### FR-02 节点：打开标签页（起始节点）

**目的**：指定采集目标页面，是后续所有节点的作用对象。

**配置项**：

| 字段 | 必填 | 类型 | 默认 | 说明 |
|---|---|---|---|---|
| 页面 URL | 是 | 文本 | 空 | 仅支持 http/https；非法 URL 运行前校验拦截 |
| 打开方式 | 是 | 单选 | 新标签页 | 新标签页 / 当前标签页（即当前窗口正在浏览的页面，仅 http/https） |
| 额外等待时间 | 否 | 数字（秒） | 0 | 页面 load 事件后再等待的时长，用于页面异步渲染内容 |
| 运行后自动关闭标签页 | 否 | 开关 | 关 | 整个工作流执行结束后关闭该标签页 |

**处理规则**：

- 执行时按配置打开（或复用当前）标签页并导航到 URL，等待页面 load 事件 + 额外等待时间后视为节点成功，后续节点均在此标签页上执行；
- 页面加载超时时间默认为 30 秒，可在全局设置中调整（10–120 秒，见 FR-01），超时判定节点失败；
- 运行期间用户手动关闭了目标标签页，则后续所有节点失败，日志提示"目标标签页已关闭"。

---

### FR-03 节点：提取内容

**目的**：按用户输入的 HTML 标签选择器和属性名称，从页面中提取文本或属性值，产出命名变量。可添加多个。

**配置项**：

| 字段 | 必填 | 类型 | 默认 | 说明 |
|---|---|---|---|---|
| 变量名 | 是 | 文本 | 空 | 同一工作流内唯一；允许中文、字母、数字、下划线 |
| 选择器类型 | 是 | 下拉 | CSS | CSS / XPath（v0.6） |
| 选择器 | 是 | 文本 + 选择按钮 | 空 | CSS 如 `h1.title`；XPath 如 `//div[@class="item"]/a`；可点击"选择元素"打开可视化选择面板（FR-09） |
| 提取类型 | 是 | 单选 | 元素文本 | 元素文本 / 属性值 |
| 属性名 | 条件必填 | 文本 | 空 | 提取类型为"属性值"时必填，如 `href`、`src`、`alt`、`data-*` |
| 多匹配处理 | 是 | 单选 | 仅第一个 | 选择器匹配多个元素时：仅第一个 / 全部（用分隔符拼接，默认换行） / **列表集合**（返回数组，供循环与 `{{#each}}` 使用）（v0.8） |
| 等待元素出现 | 否 | 数字（秒） | 5 | 在超时时间内等待元素出现，0 表示立即匹配 |
| 未匹配时 | 是 | 单选 | 停止并报错 | 停止并报错 / 置空并继续（变量值为空字符串） |
| 正则后处理 | 否 | 开关 + 表达式 | 关 | 开启后对提取结果执行 `RegExp(pattern, flags).replace(replacement)`（flags 支持 g / gi / gm / gim）（v0.6） |

**处理规则**：

- "元素文本"取元素及其后代的可见文本，自动去除首尾空白、将连续空白合并为一个空格 [Assumption, TBD]；
- "属性值"中，`href` / `src` 类属性自动基于页面地址转为绝对 URL；
- **可视化选择面板**：点击"选择元素"后，在最近浏览过的网页标签页上打开可拖动选择面板（见 FR-09）；用户确认后选择器自动回填本字段；
- **列表集合**（v0.8）：多匹配处理选"列表集合"时，变量值为全部匹配项组成的数组（空值丢弃），可被循环节点遍历、条件分支判断，或在文章组装中用 `{{#each 变量名}}…{{/each}}` 渲染；正则后处理会逐项执行；未匹配时置为空数组（"置空并继续"）；
- 选择器语法错误判定节点失败，并在日志中给出语法提示（CSS / XPath 分别提示）；
- 开启正则后处理时，先用正则替换提取值再写入变量；正则非法在运行前校验拦截；
- 节点成功后，变量值写入本次运行的数据上下文，在底部面板展示输出摘要（超长截断）。

### FR-04 节点：下载图片

**目的**：把页面中的图片下载到本地，变量值为可用于 Markdown 图片语法的引用路径。可添加多个。

**配置项**：

| 字段 | 必填 | 类型 | 默认 | 说明 |
|---|---|---|---|---|
| 变量名 | 是 | 文本 | 空 | 规则同 FR-03 |
| 图片来源 | 是 | 单选 | 页面元素选择器 | 页面元素选择器 / 变量（图片 URL）（v0.6） |
| 选择器类型 | 条件必填 | 下拉 | CSS | 选择器类型为 CSS / XPath；仅在"页面元素选择器"模式下使用 |
| 选择器 | 条件必填 | 文本 + 选择按钮 | 空 | 定位图片元素；选择面板规则同 FR-09，建议直接选择 `<img>` 元素 |
| 属性名 | 否 | 文本 | `src` | 取图片地址的属性 |
| 图片 URL 变量 | 条件必填 | 下拉 | 空 | 仅在"变量"模式下使用，通常选循环节点的当前项变量，实现多图批量下载 |
| 多匹配处理 | 是 | 单选 | 仅第一个 | 选择器模式仅支持第一个；批量下载由"批量提取 + 循环 + 变量模式"承担 |
| 引用方式 | 是 | 单选 | 本地相对路径 | 变量值 = 本地相对路径（如 `images/001.jpg`）/ 原始图片 URL（此模式下不触发下载） |
| 未匹配 / 下载失败时 | 是 | 单选 | 停止并报错 | 停止并报错 / 置空并继续 |
| 正则后处理 | 否 | 开关 + 表达式 | 关 | 对取到的图片 URL 执行正则替换 |

**处理规则**：

- 图片保存到浏览器默认下载目录下的子文件夹（默认 `{插件名}/images/`，子文件夹名可在全局设置中自定义，见 FR-01），文件名自动按 `001.扩展名` 序号生成，避免重名和非法字符；
- 下载成功即节点成功；网络错误、目标拒绝访问（如 403）判定下载失败，按"下载失败时"策略处理；
- 若用户希望在文章中引用原始图床 URL，选择"原始图片 URL"引用方式即可，不消耗下载行为；
- **多图批量下载**（v0.6）：用"批量提取"节点把页面上的多个图片地址收集为集合变量，再用"循环"遍历集合，循环体内放"下载图片"节点并选择图片来源为"变量"（指向循环当前项），即可逐张下载。

### FR-05 节点：文章组装（特殊节点）

**目的**：消费前面节点产出的变量，按用户编写的模板拼成一篇 Markdown 短文。每个工作流最多一个，建议放在最后。

**配置项**：

| 字段 | 必填 | 类型 | 默认 | 说明 |
|---|---|---|---|---|
| 文章标题 | 是 | 文本 | 空 | 同时作为下载文件名（自动剔除非法字符）；支持 `{{变量}}` 占位符 |
| Markdown 模板 | 是 | 多行文本 | 见下方默认模板 | 支持 `{{变量名}}` 占位符，运行前校验引用的变量均已定义 |

默认模板示例：

```markdown
# {{标题}}

{{正文}}

![封面]({{封面图}})
```

**集合变量支持**（v0.6）：

- 普通变量引用：`{{变量名}}`；
- 集合变量（"批量提取"产出）直接引用时按换行展开为多行；
- 块语法：`{{#each 集合名}} … {{/each}}`，块内用 `{{item}}` 表示当前项、`{{index}}` 表示序号（从 1 开始），适合生成列表型正文：

```markdown
# {{标题}}

{{#each 链接列表}}
- [{{item}}]({{item}})
{{/each}}
```

- **对象集合**（v0.7，批量提取配置了字段映射时）：每个列表项是 `{ id, name, date }` 形式的对象，块内用 `{{item.字段名}}` 取值：

```markdown
{{#each 文章列表}}
- {{item.id}} | {{item.name}} | {{item.date}}
{{/each}}
```

  直接引用对象集合变量（如 `{{文章列表}}`）时，按行输出每个对象的 JSON，便于调试。

**处理规则**：

- 执行时将模板中的 `{{变量名}}` / `{{#each}}` 块渲染为实际内容；变量值为空时替换为空字符串；
- 校验：模板引用了不存在的变量名、或 `#each` 引用的变量不是集合变量时，运行前校验失败并列出问题，禁止运行；
- 节点成功后产出完整 Markdown 文本，进入结果输出（FR-07）；
- 位于循环体内时，每次循环产出一篇独立 Markdown，结果面板可逐篇切换、批量下载。

### FR-06 执行引擎与运行反馈

**目的**：按顺序驱动节点执行，让用户清楚看到每一步的状态与失败原因。

**触发**：点击编辑器顶部"运行"按钮。

**节点状态机**：

| 状态 | 含义 | 可转移自 |
|---|---|---|
| 未运行 | 初始状态 | — |
| 运行中 | 正在执行 | 未运行 |
| 成功 | 执行完成，产出已写入上下文 | 运行中 |
| 失败 | 执行出错，流程终止 | 运行中 |
| 跳过 | 前序节点失败未执行，或条件分支不成立整段跳过 | 未运行 |

**处理规则**：

1. 运行前校验：起始节点 URL 合法、各节点必填项完整、变量名唯一、循环/条件区间配对完整、集合变量引用有效、正则合法、组装模板引用已定义；校验失败时高亮问题节点并逐条提示，不进入执行；
2. 顺序执行节点列表（区间块按递归方式执行），同一时间只允许一个运行实例；
3. 每个节点执行时实时更新状态（节点列表中以颜色 / 图标区分），底部日志面板记录每节点的输入摘要与结果；
4. 节点失败即终止流程，后续节点标记"跳过"，日志给出失败原因（如"选择器无匹配元素""页面加载超时""图片下载失败：403"）；
5. 配置了"置空并继续"的节点在失败时不终止流程，变量置空，状态记为"成功（空值）"；
6. **循环**：读取集合变量，按项数重复执行"循环开始 ~ 循环结束"之间的节点，每次把当前项写入"当前项变量"，并清空循环结束后残留的当前项；
7. **条件分支**：求值成立时执行"条件分支 ~ 条件结束"之间的节点，不成立时整段标记"跳过"并继续后续节点。

### FR-07 结果输出（复制 / 下载）

**目的**：把组装节点产出的 Markdown 交付给用户。

**触发**：工作流执行成功（存在组装节点且其执行成功）后，底部面板切换到结果页。

**行为**：

- **预览**：展示 Markdown 源码及渲染效果对照；
- **复制**：一键将 Markdown 源码写入剪贴板（纯文本格式），按钮反馈"已复制"；
- **下载**：将 Markdown 保存为 `.md` 文件，文件名为文章标题（非法字符替换为 `-`），保存到浏览器默认下载目录；
- **多篇结果**（v0.6）：循环内组装产出多篇时，结果面板顶部出现下拉选择器可逐篇切换查看/复制/下载，另有"全部下载"按钮批量保存；
- 工作流中没有组装节点时允许运行（用于调试各提取节点），但结果页不提供复制 / 下载，仅展示各节点输出摘要。

### FR-08 图标弹窗（工作流快捷入口）

**目的**：点击扩展图标即可快速触达各工作流，无需先打开编辑器主页。

**触发**：点击浏览器工具栏扩展图标。

**形态**：浏览器原生 popup 弹窗，展示工作流列表（按最近更新排序），底部提供"管理全部工作流"入口（打开编辑器主页）。

**规则**：

- 每个工作流条目为一行：**名称 + 更新时间（相对时间）**，右侧 **▶ 运行**（打开该工作流的编辑器标签页并立即开始执行）与 **⋯ 更多**（重命名 / 删除）；点击名称进入编辑器；
- 重命名为内联编辑（Enter / 失焦保存，Esc 取消）；删除需二次点击确认（弹窗内不使用原生 confirm，避免关闭弹窗）；
- 顶部提供"新建"：创建新工作流并直接进入编辑器；
- 弹窗内不执行采集逻辑——弹窗关闭即销毁，运行统一交由编辑器标签页完成（同决策 #1 的执行环境约束）；
- 弹窗与编辑器读写同一份本地数据，任何一处的修改即时生效；
- 顶部另有**选择元素**图标按钮：点击后关闭弹窗，并在当前网页上打开可视化选择面板（FR-09），用于临时查看/复制页面元素的选择器与属性。

### FR-09 可视化元素选择面板

**目的**：在真实页面上点选元素，直接拿到 CSS 选择器与全部属性值，避免手写选择器、手动抄属性。

**触发**：编辑器提取/图片节点的"选择元素"按钮，或图标弹窗的"选择元素"图标。

**形态**：注入到目标网页右上角的浮层面板，可拖动移动（鼠标移入时左上角显示拖动图标），不影响页面原有布局。

**组成**：

| 区域 | 内容 |
|---|---|
| 头部 | 拖动图标（悬停显示）、应用名、**可视化选择开关**、关闭 |
| 选择器行 | 只读选择器 + 类型下拉（CSS / XPath，v0.6）、复制图标、**多元素匹配按钮**（v0.7）、选择父元素 ↑、选择第一个子元素 ↓ |
| 属性区 | 选中元素的标签名与全部属性（含 `id`、`class`、`href`、`target` 等），每个属性值带复制图标 |
| 底部 | 操作提示；编辑器侧另有"使用此选择器"按钮确认回填 |

**规则**：

- 开关关闭时页面正常浏览、不可选择；开启后悬停元素高亮，单击即选中并渲染其属性；
- 选择器生成规则：CSS 优先 `#id`，否则沿 DOM 向上拼接 `tag.class` / `:nth-of-type` 直至唯一；XPath 优先 `//*[@id="x"]`，否则生成带层级索引的绝对路径（如 `/html[1]/body[1]/div[2]/a[1]`），切换类型时即时重算；
- 复制：点击属性行或选择器行的复制图标，将对应值写入剪贴板并轻提示"已复制"；
- **多元素匹配**（v0.7）：点击选择器行内的列表图标按钮可开启/关闭，开启时按钮呈绿色激活态；开启后选择器从"唯一选择器"切换为"同类选择器"（如 `div.item`，XPath 为 `//div[contains(@class,"item")]`），页面上所有匹配元素同时显示绿色描边，底部提示"共 N 个同类元素"；关闭后恢复唯一选择器并清除描边；
- 多元素匹配开启时点击"使用此选择器"：提取节点会自动把"多匹配处理"设为"全部"，批量提取节点则天然按集合处理；
- 编辑器触发的面板，点击"使用此选择器"后回填到当前节点并关闭；直接关闭面板则不回填；
- 面板可重复打开（再次触发会替换旧面板）；仅支持 http/https 页面；Esc 先退出选择态、再关闭面板。

### FR-10 节点：批量提取与循环（集合变量）

**目的**：把列表页中的多条数据一次性收集为集合变量（list），并支持翻页累积；循环节点用于逐项处理集合（批量提取详情、多图下载、逐条生成多篇文章）。

#### FR-10.1 批量提取

**配置项**：

| 字段 | 必填 | 类型 | 默认 | 说明 |
|---|---|---|---|---|
| 变量名 | 是 | 文本 | 空 | 产出**集合变量**（数组），供循环 / 文章组装引用 |
| 选择器类型 | 是 | 下拉 | CSS | CSS / XPath |
| 选择器 | 是 | 文本 + 选择按钮 | 空 | 匹配多条数据，如 `.list .title`、`//div[@class="item"]` |
| 提取类型 | 是 | 单选 | 元素文本 | 元素文本 / 属性值（如 `href`、`src`）；配置了字段映射时隐藏 |
| 属性名 | 条件必填 | 文本 | 空 | 提取类型为"属性值"时必填 |
| 字段映射 | 否 | 动态字段列表 | 空 | 每个字段 = 字段名（key）+ 选择器（相对当前列表项，可留空表示元素本身；支持"选择元素"点选并自动写成相对选择器）+ 取值方式（文本 / 属性）+ 属性名；配置后每个列表项输出对象（v0.7 / v0.8） |
| 翻页采集 | 否 | 开关 | 关 | 开启后循环点击"下一页"并累积本页数据 |
| 下一页选择器 | 条件必填 | 文本 + 类型 | 空 | 翻页按钮 / 链接的选择器（CSS / XPath） |
| 最大页数 | 否 | 数字 | 5 | 翻页上限，1–50 |
| 每页等待 | 否 | 数字（秒） | 2 | 点击下一页后等待内容加载的时间 |
| 正则后处理 | 否 | 开关 + 表达式 | 关 | 对每一项分别执行正则替换 |

**处理规则**：

- 收集当前页所有匹配元素的提取值（空值丢弃），按字符串（对象按 JSON）去重后累积；
- **字段映射**（v0.7）：未添加字段时每个列表项是一个字符串；添加字段后每个列表项变成一个对象，字段选择器相对当前列表项查找（XPath 请以 `.//` 开头），全部字段取值为空的对象被丢弃；字段名必填、不可重复，取属性值时属性名必填；
- **字段点选**（v0.8）：每个字段行提供"选择元素"按钮，点选后浮层会把选择器转换为**相对当前列表项**的写法（优先项内唯一的 `tag.class`，否则逐级 `tag:nth-of-type(n) > …`；选中列表项本身则为空，表示取当前项元素）；仅支持 CSS 列表项选择器，未填写列表项选择器时提示先配置；字段映射下方提供"怎样填写"示例说明；
- 对象集合在模板中通过 `{{item.字段名}}` 引用，例：`{{#each 文章列表}}{{item.id}} {{item.name}}{{/each}}`；
- 翻页模式下：点击下一页 → 等待"每页等待"秒 → 重新收集，直到找不到可点击的下一页或达到最大页数；
- 选择器无匹配时集合为空，节点状态记为"空"，不阻断流程；
- 集合变量在输出摘要中展示项数与逐行内容。

#### FR-10.2 循环

**配置项**：

| 字段 | 必填 | 类型 | 默认 | 说明 |
|---|---|---|---|---|
| 遍历集合 | 是 | 下拉 | 空 | 选择前面产出的集合变量 |
| 当前项变量 | 是 | 文本 | `item` | 循环体内用 `{{当前项变量}}` 引用当前项 |

**处理规则**：

- 循环为区间块：`循环开始 … 循环结束`，区间内的节点按集合项数重复执行；
- 每次迭代把当前项写入"当前项变量"，可在提取 / 图片 / 组装节点中以 `{{变量}}` 引用；
- 集合为空时循环体整段跳过并记录日志；
- 循环结束后清空当前项变量；
- 支持嵌套（内层循环需使用不同的当前项变量名）。

### FR-11 节点：条件分支

**目的**：按变量取值决定一段节点是否执行，避免无意义采集或产出。

**配置项**：

| 字段 | 必填 | 类型 | 默认 | 说明 |
|---|---|---|---|---|
| 判断变量 | 是 | 下拉 | 空 | 选择前面产出的变量 |
| 条件 | 是 | 下拉 | 不为空 | 不为空 / 为空 / 等于 / 不等于 / 包含 / 不包含 / 大于（数字）/ 小于（数字） |
| 比较值 | 条件必填 | 文本 | 空 | 条件为"等于 / 不等于 / 包含 / 不包含 / 大于 / 小于"时必填 |

**处理规则**：

- 条件分支为区间块：`条件分支 … 条件结束`；条件成立时执行区间内节点，不成立时整段标记"跳过"并继续后续节点；
- 比较为字符串包含 / 相等判断，"大于 / 小于"按数值比较；集合变量以换行拼接后的文本参与比较；
- 条件结束节点固定存在，不可单独删除（删除条件分支会连同区间一并删除）。

### FR-12 工作流保存 / 导入 / 导出

**目的**：多套流程的备份、迁移与共享。

**触发**：编辑器顶部「文件 ▾」菜单，或主页顶部「导入」按钮。

**行为**：

- **保存工作流**：立即将当前状态写入本地存储（编辑过程本身也会自动保存，此操作用于确认落盘）；
- **导出当前工作流**：下载单个 JSON 文件；
- **导出全部工作流**：把本地全部工作流打包为一个 JSON 文件；
- **导入工作流**：选择 JSON 文件后解析并追加到本地列表（自动重新生成 id，不覆盖已有工作流），导入完成后在列表页 / 日志中给出提示。

**文件格式**（版本化，便于后续兼容）：

```json
{
  "app": "TopData",
  "kind": "workflow | bundle",
  "version": 1,
  "exportedAt": "2026-11-11T00:00:00.000Z",
  "workflows": [
    { "name": "示例工作流", "updatedAt": 1762800000000, "nodes": [{ "type": "openTab", "config": {} }] }
  ]
}
```

**规则**：

- 导入时校验 `workflows` 存在且节点数组非空；缺失 / 非法节点类型被忽略；缺少起始节点时自动补一个"打开标签页"节点并置于首位；
- 导入的节点配置与当前版本的默认配置合并，缺失字段取默认值；
- 文件按 UTF-8 编码，中文名称原样保留。

## 6. 共享规则与异常

### 6.1 通用规则

- **变量命名**：必填、同一工作流内唯一，允许中文、字母、数字、下划线，长度 ≤ 50；引用语法统一为 `{{变量名}}`；
- **浏览器权限**：安装 / 首次运行时向用户申请——读取和更改所访问网站的数据（用于页面内提取）、管理下载（保存图片与 .md）、读取标签页（打开与定位目标页）；
- **隐私**：所有页面数据、变量、Markdown 结果仅存在于用户本地，插件不发起任何与采集无关的网络请求；
- **登录态**：插件复用用户浏览器会话，需要登录的页面由用户自行登录后即可采集，插件不处理账号密码。

### 6.2 异常清单

| 场景 | 产品行为 |
|---|---|
| URL 为空 / 非法 | 运行前校验拦截，标红起始节点 |
| 页面加载超时（30s） | 起始节点失败，流程终止 |
| CSS 选择器语法错误 | 节点失败，日志提示语法问题 |
| 选择器无匹配元素 | 按节点"未匹配时"策略：停止报错 / 置空继续 |
| 图片下载失败（403、网络错误等） | 按节点"下载失败时"策略处理 |
| 模板引用未定义变量 | 运行前校验拦截，列出未定义变量名 |
| 循环 / 条件区间未配对 | 运行前校验拦截，提示"缺少循环结束 / 条件结束节点" |
| 集合变量为空 | 循环体整段跳过，日志提示"集合为空" |
| 字段名为空 / 重复 | 运行前校验拦截，提示第几个字段有问题 |
| 正则表达式非法 | 运行前校验拦截，并在该节点标红提示 |
| 导入文件非法 / 缺少有效工作流 | 提示导入失败，不写入本地数据 |
| 运行中用户关闭目标标签页 | 后续节点全部失败，日志明确提示 |
| 剪贴板写入失败 | 结果页提示复制失败，建议改用下载 |
